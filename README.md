# STR test results

Dashboard of the Amazon US strikethrough (STR) price tests: what it takes to get the List Price shown struck through on the product page.

Live page: https://umair0786bot.github.io/STR/

- `index.html` is the whole dashboard (no build step). Product images load from Amazon.
- Data: Ecotero Command Center order data through 21 Oct 2026 and the team's STR test sheet.
